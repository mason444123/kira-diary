# Kira Diary — логика работы MVP

## Решение пользователя

Пользователь не записывает голосовые на сайте. Голосовые отправляются прямо в диалог с Кирой/ассистентом. Сайт — только приватная витрина данных.

## Workflow

1. Иван отправляет голосовое сообщение в диалог.
2. Ассистент получает/распознаёт текст голосового.
3. Ассистент извлекает факты дня.
4. Ассистент считает Kira Score.
5. Ассистент обновляет данные сайта.
6. Сайт показывает обновлённый день и месяц.

## Пустое состояние

Пока записей нет:

- Оценка Киры: `—`
- Подъём: `—`
- Сон: `—`
- Привычки: `0 / 6`
- Голос: `—`
- Месяц: `— средняя`
- Записи: `0 записей`
- Все точки месяца пустые/полупрозрачные.

## Kira Score

Оценка от 0.0 до 10.0.

Весовые блоки:

- Сон и режим — 25%
- Полезные действия — 30%
- Привычки — 20%
- Состояние — 15%
- Честность/осознанность — 10%

На сайте не показывать длинные комментарии Киры. Только число и структурные поля.

## Обновление дня

Если пользователь отправил голосовое за сегодня:

- обновляем текущую дату;
- score становится числом, например `7.3`;
- поля Подъём/Сон/Привычки/Голос заполняются, если данные есть;
- точка текущего дня получает цвет по score;
- средняя месяца пересчитывается;
- количество записей месяца увеличивается/обновляется.

Если пользователь прислал уточнение за тот же день:

- не создавать дубль;
- обновить существующую запись за дату;
- пересчитать score.

## Цвета точек месяца

- 8.0–10.0 — светлый warm lime / green
- 6.0–7.9 — песочный yellow
- 4.0–5.9 — orange
- 0.0–3.9 — soft red
- null — empty translucent dot

## Интерфейс

Сайт не должен иметь кнопку записи голосового. Голосовые идут через диалог.

Главный экран:

- ДНЕВНИК КИРЫ
- Сегодня
- pill: количество записей
- Оценка Киры
- Подъём / Сон / Привычки / Голос
- Месяц точками

Минимализм важнее количества статистики.
