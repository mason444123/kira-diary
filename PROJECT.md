# Kira Diary — личный AI-дневник

Дата фиксации: 2026-05-13

## 1. Суть проекта

Kira Diary — закрытый личный сайт-дневник, куда попадают данные из ежедневных голосовых сообщений.

Поток:

1. Иван в конце дня отправляет голосовое сообщение Кире.
2. Кира переводит голос в текст.
3. Из текста извлекаются факты дня.
4. Кира считает числовую оценку дня — **Kira Score**.
5. Данные сохраняются в приватную базу.
6. На сайте Иван видит минималистичный дневник месяца.

Главная формула продукта:

> voice → day → score → month

Это не должен быть перегруженный productivity dashboard. Это должен быть спокойный, красивый, приватный журнал с одной главной цифрой.

---

## 2. Главные принципы

- Светлый минималистичный дизайн.
- Премиальный, спокойный, личный вайб.
- Не перегружать интерфейс статистикой.
- Не делать таблицы на 31 день, тяжелые графики, много колонок.
- Не делать длинные AI-комментарии Киры.
- Кира должна давать **цифру**, а не словесный разбор.
- Все сложные вычисления могут быть внутри, но интерфейс должен оставаться простым.

---

## 3. Kira Score

Kira Score — итоговая оценка дня от `0.0` до `10.0`.

В интерфейсе показывается только число, например:

```text
7.5
```

Без прямых словесных комментариев типа “день слит”, “молодец”, “плохой день”.

Допустимо использовать мягкую цветовую индикацию:

- 8.0–10.0 — мягкий зеленый;
- 6.0–7.9 — спокойный желто-зеленый / нейтральный;
- 4.0–5.9 — теплый песочный / оранжевый;
- 0.0–3.9 — мягкий красно-розовый.

Оценка — это не моральная оценка человека, а “температура дня” по личным критериям.

### Предварительная формула оценки

Итоговая оценка складывается из 5 факторов:

| Фактор | Вес |
|---|---:|
| Сон и режим | 25% |
| Полезные действия | 30% |
| Привычки | 20% |
| Состояние | 15% |
| Честность / осознанность | 10% |

### 1. Сон и режим — 25%

Учитывается:

- время подъема;
- время отхода ко сну;
- длительность сна;
- стабильность режима.

### 2. Полезные действия — 30%

Учитывается:

- был ли прогресс по важным задачам;
- была ли работа над проектом / деньгами / развитием;
- были ли реальные результаты, а не просто занятость.

### 3. Привычки — 20%

На старте не больше 5–7 привычек:

- подъем до целевого времени;
- сон до целевого времени;
- работа над главным;
- тренировка / движение;
- нормальное питание;
- без сильного залипания;
- план на завтра.

Статусы привычки:

- `1` — выполнена;
- `0.5` — частично;
- `0` — не выполнена.

### 4. Состояние — 15%

Учитывается:

- настроение;
- энергия;
- стресс;
- тревога;
- самочувствие.

Плохое состояние не должно автоматически уничтожать оценку, если день был восстановительным или человек сделал важный минимум.

### 5. Честность / осознанность — 10%

Поощряется сам факт регулярной записи и честной фиксации дня.

Учитывается:

- было ли голосовое;
- признаны ли причины слабого дня;
- есть ли понимание, что повлияло на день.

## 4. Структура сайта на первом этапе

Всего 3 основных экрана:

1. **Today**
2. **Month**
3. **Trends**

Без отдельных тяжелых разделов под сон, привычки, продуктивность, здоровье, архив и т.д. Смежные темы объединяются.

---

## 5. Экран Today

Главный экран дня.

Показывает:

- большую оценку Kira Score;
- дату;
- время подъема;
- время сна / отхода ко сну;
- привычки `4/6`;
- длительность голосового;
- короткий summary при необходимости.

Пример структуры:

```text
Kira

Today
12 January

        7.5
     Kira Score

Wake up      09:20
Sleep        01:10
Habits       4/6
Voice        2:48

[ Add voice note ]
```

Важное: главный герой экрана — одна большая цифра.

---

## 6. Экран Month

Минималистичный обзор месяца.

Не делать перегруженный календарь с колонками, таблицами, множеством строк.

На данном этапе календарь должен выглядеть как **мягкая сетка маленьких кружков / точек**, где каждая точка — день месяца.

Пример:

```text
January

6.8 average
24 days logged

● ● ● ● ● ● ●
● ● ● ● ● ● ●
● ● ● ● ● ● ●
● ● ● ● ● ● ●
● ● ●
```

Цвет точки зависит от Kira Score.

По клику / тапу на точку открывается конкретный день.

Что показывать сверху:

- средняя оценка месяца;
- количество записанных дней;
- возможно, лучший день / текущий streak, но только если это не перегружает.

Что НЕ делать:

- таблицу привычек на 31 день;
- тяжелый календарь с колонками;
- много графиков;
- много подписей на каждой дате;
- игровые элементы.

---

## 7. Экран Trends

Мягкая статистика без перегруза.

Показывать только 3–5 ключевых показателей:

```text
Trends

Average score     6.8
Logged days       24/31
Average wake up   09:46
Average sleep     6h 42m
Habits            64%
```

Можно добавить маленькие тонкие линии/спарклайны, но без тяжелых графиков.

## 8. Дизайн-код

Направление: **warm minimal / soft minimal / calm personal journal**.

Ассоциации:

- личный дневник;
- Apple-style simplicity;
- Reflect / Day One / Stoic;
- премиальный приватный инструмент;
- много воздуха;
- мягкие карточки;
- спокойная типографика.

## 10. Что не делать

- Не делать BI-dashboard.
- Не делать много разделов.
- Не делать длинные комментарии Киры.
- Не делать таблицы привычек по дням месяца.
- Не делать слишком много цветов.
- Не делать перегруженные графики.
- Не делать gamification / XP в первой версии.

- Не делать интерфейс, который вызывает чувство вины.

## 11. MVP

Первая версия должна уметь:

1. Принять голосовое.
2. Распознать текст.
3. Извлечь данные дня.
4. Посчитать Kira Score.
5. Сохранить день.
6. Показать Today.
7. Показать Month с точками дней.
8. Показать Trends с 3–5 метриками.

Минимальное ядро:

```text
Today → big score
Month → dots calendar
Trends → few numbers
```

## 12. Текущий статус решения

На данный момент зафиксировано:

- проект называется условно **Kira Diary**;
- визуальное направление — светлый warm minimal;
- календарь — сетка маленьких точек/кружков по дням, без колонок и таблиц;
- Kira Score — только числовой, без прямых комментариев;
- сайт должен быть приватным;
- интерфейс должен быть красивым, спокойным и не перегруженным.
